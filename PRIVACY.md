# Privacy Policy

## Data Processing

This web application runs tax-benefit microsimulations on a **synthetic (artificial) dataset** that ships with the application. No real household or personal data is involved.

### Information We Don't Collect

- We do not require or accept any user data uploads
- We do not collect personal information
- We do not track individual user behavior
- We do not share data with third parties

### How the Tool Works

- The simulation uses the pre-loaded synthetic DEVMOD input dataset included with the application
- Users only modify policy parameters (tax rates, benefit amounts, thresholds)
- Results are computed server-side per request and are not stored
- Data transmission uses HTTPS encryption when deployed
